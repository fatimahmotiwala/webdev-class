My Projects

Khidmat Project in collaboration with SIUT

The SIUT Clinical ICD Coding System (SCICS) is an NLP-powered application that assists medical coders by suggesting ICD-10 diagnosis and procedure codes from discharge summaries. It features a PyQt6 desktop interface, a FastAPI backend, and confidence-scored suggestions that coders can accept, reject, or edit, supported by a chatbot and a feedback loop that retrains the model from coder corrections.

Travel and Tour Booking Agency

This project involved architecting a modular ticket booking system in C++ using core object-oriented programming principles. System components such as routes, transport modes, pricing, and add-ons were modeled through class hierarchies, while an interactive GUI built with SFML enabled seamless booking and navigation for users. The system also implemented dynamic pricing logic based on user selections and constraints. By leveraging inheritance, encapsulation, and polymorphism throughout, the project achieved a scalable and maintainable architecture suited for course-level object-oriented design.

Epidemic Outbreak Detector

The Epidemic Outbreak Detection and Analysis System is an interactive application built to analyze and visualize epidemic data across different regions. It tracks case trends and growth rates while assessing outbreak risk levels, using sparse matrix representations and KD-Tree based region comparisons to efficiently identify patterns and monitor potential disease outbreaks. The system combines data structures and visualization techniques to support early detection and informed decision-making in tracking regional health trends.
